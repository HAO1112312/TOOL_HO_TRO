# ODX CAPTURE AUTO-PILOT SUITE (v3.1)
Hệ thống điều phối, đồng bộ và kiểm định ghi hình Odx Capture đa máy chuyên nghiệp.

## 🚀 Tính năng nổi bật
- **Tương thích toàn diện:** Hỗ trợ Odx Capture phiên bản mới nhất (0.3.5 / 0.3.4).
- **Auto-Join & Auto-Ready 100%:** Tự động điền mã phòng, đóng hộp thoại và bật trạng thái Sẵn sàng trên các Máy Con (Player).
- **Chống lỗi quay Solo:** Tuyệt đối không gửi phím F10 khi chưa vào đúng phòng hoặc khi Odx ở chế độ đơn.
- **Cập nhật Online (GitHub):** Người chơi ở xa chỉ cần bấm nút `🚀 Cập Nhật Online` trên giao diện để tự động đồng bộ mã nguồn mới nhất.
- **Thu thập Log & Xuất Gói Debug:** Ghi nhận nhật ký JSONL độ trễ mili-giây và xuất gói ZIP kiểm định chỉ bằng 1 cú click `📦 Xuất Log Debug`.

## 📦 Hướng dẫn cài đặt cho Player
1. Tải file `Tool_Tu_Dong.zip` từ repository này.
2. Giải nén toàn bộ các file trong zip thả trực tiếp vào thư mục Odx Capture (nơi có file `Odx Capture.exe`).
3. Chạy file `2_CHAY_PLAYER_TU_DONG.bat` (hoặc `CHAY_TOOL_AUTO_PILOT.bat`).
4. Khi có bản cập nhật mới, chỉ cần mở Tool hoặc bấm `🚀 Cập Nhật Online` để tự động nâng cấp.
